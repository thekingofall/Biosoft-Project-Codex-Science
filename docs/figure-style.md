# Figure style

The plotting palette is defined once in `code/figure_tools.py` as `PALETTE`:

| Colour | Hex |
|---|---|
| Blue | #355C7D |
| Green | #52796F |
| Terracotta | #B56B45 |
| Violet | #806A87 |
| Ochre | #BA994F |
| Slate | #6B8793 |

R receives these values through the saved figure parameters. Use Arial, English labels, black axes, visible points and lines, and external legends. Output both PDF and PNG. Keep plotting data and scripts with the analysis; generated parameter JSON records the input and script SHA-256. Composition preserves existing panel pixels and adds Arial letters.
