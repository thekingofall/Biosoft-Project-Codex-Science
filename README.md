# Codex Science

**English** · [简体中文](README.zh-CN.md)

### Scientific questions. Traceable data. Reproducible work.

Codex Science brings a scientific workflow into Codex: find evidence, retrieve data, run an appropriate analysis, and produce readable figures and reports. Invoke it with **`$codex-science`**.

The local `science-bio` connector currently exposes **224 tools across 23 domains** with a prepared Claude Science 0.1.60 distribution. This repository contains the adapter, skill, setup scripts and tests. Connector source files are supplied separately on your own machine.

## What you can do

| Research step | Support |
| --- | --- |
| Find evidence | Route queries to literature and scientific database connectors |
| Retrieve data | Genes, proteins, variants, compounds, clinical trials and omics archives |
| Analyze a dataset | Guide Codex to inspect study design and use an available R/Python environment |
| Make figures | R-first instructions, plot-ready data, PNG/PDF exports |
| Reproduce results | Preserve query parameters, source identifiers, scripts and inputs |

## Get started

**Requirements:** Windows, Python 3.12, `uv`, Codex CLI, and a separately prepared local Claude Science 0.1.60 asset directory with its extraction manifest. See [setup and source requirements](docs/setup.md) before installing. The workflow skill can guide analysis; data connectors require those external assets. Scientific model runtimes are configured separately.

```powershell
git clone https://github.com/thekingofall/Biosoft-Project-Codex-Science.git
cd Biosoft-Project-Codex-Science
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.lock.txt
$env:CODEX_SCIENCE_RELEASE = 'D:\your-assets\0.1.60'
.\code\install-codex.ps1
.\.venv\Scripts\python.exe -X utf8 .\code\verify_mcp.py
```

Reload Codex skills/MCP connections, then ask:

> $codex-science Look up human BRCA1, retrieve its protein sequence, and produce a short report with source identifiers.

> $codex-science Inspect this expression matrix and sample sheet, clarify the comparison, then run the appropriate differential analysis and export R figures.

## Know what is ready

```powershell
.\codex-science.ps1 status
.\codex-science.ps1 tools --query ensembl --limit 3
.\codex-science.ps1 tools --domain literature
```

The status command separates present configuration from previous online checks. Tool search reads the catalog generated by `verify_mcp.py`.

The original local acceptance passed MCP initialization, 224-tool discovery in Codex, Ensembl BRCA1 lookup, UniProt P04637 sequence retrieval and PubChem aspirin lookup. Remaining endpoints have not been individually tested online. See [validation scope](docs/validation.md).

## Credentials

Copy `user-settings.example.toml` to `user-settings.toml` and fill the fields needed for your task. NCBI queries require a contact email; OpenAlex requires an API key. NCBI's API key is optional. Restart the MCP connection after changes. Keep this ignored file local.
