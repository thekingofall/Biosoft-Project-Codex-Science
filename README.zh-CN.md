# Codex Science

[English](README.md) · **简体中文**

**在 Codex 里查文献、找数据、做分析、画科研图。**

Codex Science 是一个面向生物医学研究的 Codex 工具包。它把常用科研数据库连接到 Codex，让你用自然语言描述需求，由 Codex 调用相应工具查询资料、获取数据，并结合你的 R、Python 或服务器环境继续分析。

例如，你正在研究一个基因，可以让 Codex 帮你查它的编号、蛋白序列、相关文献和公开数据集；拿到自己的表达矩阵后，也可以接着让 Codex 检查分组、编写分析脚本、绘图并整理结果。

**适合已经在使用 Codex，希望把它用于文献调研、生物信息分析和科研日常工作的用户。** 当前提供 Windows 安装方式。数据库查询功能需要另行准备本地连接器资源，具体见[安装说明](docs/setup.md)。

## 能做什么

### 查文献，了解一个研究问题

通过 PubMed、arXiv、OpenAlex 等服务检索论文，获取文献信息，并让 Codex 按你的研究问题整理。

适合做课题背景调研、梳理某个基因的研究进展、收集一种方法的相关论文。你可以要求结果带上题目、年份、来源编号或链接，方便回到原文核对。

### 查基因和蛋白，整理分散的信息

查询基因的标准编号、基因组位置、蛋白序列、功能注释和通路映射。相关服务包括 Ensembl、UniProt、GO 和 Reactome。

例如，手里有一份候选基因名单时，可以让 Codex 整理基因编号、已知功能和相关通路，作为后续筛选与解释的资料。

### 找公开数据，寻找可比较的研究

检索 GEO、ArrayExpress、PRIDE 等数据资源，查看与组织、疾病或实验类型相关的项目记录。

适合寻找参考队列、独立验证数据或已有研究。检索到数据集后，可以继续让 Codex 阅读项目信息，核对样本类型和实验设计，帮助你判断是否值得下载。

### 查化合物、药物与临床研究

查询化合物标识符、药物相关记录和临床试验信息，连接 PubChem、ChEMBL、ClinicalTrials.gov 等数据来源。

例如，输入一种化合物的名称，让 Codex 帮你核对标准编号，再整理相关靶点资料或研究记录。

### 查结构与相互作用

查询 PDB、AlphaFold DB 中已有的结构记录，以及 STRING 等来源的蛋白相互作用信息。

适合给蛋白功能研究补充结构背景，或为一组候选蛋白查找已有的相互作用资料。

### 接着分析自己的数据，整理图和报告

提供数据文件和样本信息后，Codex Science 的工作流程会引导 Codex 先弄清楚研究目标、分组和数据特点，再调用你现有的分析环境编写、运行代码。

绘图默认使用 R，配合保存绘图数据、脚本和 PNG/PDF 文件。后续调整配色、字号或布局时，可以沿用这些材料。

这一部分依赖 Codex 和你已有的计算环境。具体统计方法需要根据实验设计选择，R 包、Python 包与科学模型的运行环境也需要按任务配置。

## 试着这样问它

安装后，在 Codex 对话中输入 `$codex-science`，再描述你的任务。

**了解一个基因**

> $codex-science 我正在研究人类 BRCA1。请整理它的 Ensembl 编号、基因组位置和 UniProt 蛋白序列，把来源链接一起给我。

**为课题找文献**

> $codex-science 帮我检索 T 细胞衰老与线粒体功能相关的论文。按研究问题分组，列出每篇文章的主要发现和原文链接。

**寻找可以使用的公开数据**

> $codex-science 帮我在 GEO 中找人类外周血衰老相关的转录组数据。先整理数据集编号、实验类型和可获取的样本信息，再告诉我哪些研究值得进一步查看。

**分析手上的表达矩阵**

> $codex-science 这里有表达矩阵和样本分组表。请先检查数据类型、分组和批次，再根据实验设计做差异分析。用 R 画图，保存图件、绘图数据和脚本。

这些是任务示例。文献和数据库查询取决于对应服务的访问条件；数据分析需要提供真实数据、样本信息和可用环境。

## 它怎样与 Codex 配合

| 部分 | 在你工作时负责什么 |
| --- | --- |
| Codex | 理解问题、选择工具、编写和执行分析代码、解释结果 |
| `$codex-science` 技能 | 帮助 Codex 按科研任务组织检索、分析、绘图和交付 |
| `science-bio` 数据连接器 | 向科研数据库发起查询，把记录返回给 Codex |
| 你的计算环境 | 运行 R、Python 和任务需要的科学软件 |

当前适配的连接器包含 **23 个领域、224 项查询操作**。数据库查询工具与分析流程指引一起使用，让你可以在同一个 Codex 对话中持续推进工作。

## 如何安装

准备好 **Windows、Codex CLI、Python 3.12 和 uv**，然后按[安装指南](docs/setup.md)操作。

**还需要一份已准备好的 Claude Science 0.1.60 本地连接器目录和对应清单。** 这个 GitHub 仓库提供适配代码、技能和安装脚本，连接器资源由使用者在本机单独提供。安装指南列出了所需目录和配置方法。

安装完成后，重新加载 Codex 的技能和 MCP 连接，即可使用 `$codex-science`。MCP 是 Codex 调用这些数据库工具的连接方式。

部分服务还需要填写自己的访问配置：

| 服务 | 需要准备什么 |
| --- | --- |
| PubMed 等 NCBI 接口 | 联系邮箱；NCBI API Key 可选 |
| OpenAlex | API Key |

配置填写在本机的 `user-settings.toml` 中，参考仓库内的示例文件。详细步骤见[安装指南](docs/setup.md)。

## 常见问题

**在哪里使用？**

在 Codex 对话中使用。输入 `$codex-science` 后写下你的需求，也可以让 Codex 调用 `science-bio` 中某个具体工具。

**我需要会写代码吗？**

可以先用自然语言描述任务，由 Codex 编写代码。做正式分析时，仍需要你提供清楚的实验设计、样本信息和判断标准，并核对结果是否符合研究问题。

**能连接我的服务器做分析吗？**

可以让 Codex 使用你已配置并授权访问的服务器环境。服务器连接、数据路径、软件依赖与计算资源，需要按你的实际项目设置。

**克隆仓库后就能查询数据库吗？**

还需要准备安装指南中的本地连接器资源，并完成相应服务的访问配置。缺少这些材料时，数据库连接步骤暂时无法完成。

**所有功能都能直接用于我的项目吗？**

需要结合你的数据和环境判断。当前适配版本为 Claude Science 0.1.60，部分接口需要邮箱或密钥，上游服务也可能变化。已实际检查的范围记录在[验证说明](docs/validation.md)。
